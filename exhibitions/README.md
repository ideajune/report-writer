# 📂 전시회별 아카이브 및 파일 관리 가이드 (Exhibitions Archive)

본 디렉터리는 참관한 전시회별로 수집된 **원본 자료(PDF)**, **현장 사진**, **결과 보고서(Word/JSON)**를 분리 보관하는 통합 아카이빙 저장소입니다.

---

## 🗂️ 폴더 구조 및 명명 규칙

```text
exhibitions/
├── 01_인공지능페스타_2026/
│   ├── raw/                 # 주최측 공식 가이드북, 쇼가이드, 부스 배치도, 리플릿 (PDF/스캔)
│   ├── photos/              # 스마트폰/카메라로 촬영한 현장 스케치 원본 사진
│   └── reports/             # 산출물: 완성된 결과 보고서 (.docx) 및 웹앱 동기화 데이터 (.json)
│
├── 02_국제양자산업대전_2026/
│   ├── raw/
│   ├── photos/
│   └── reports/
│
└── 00_공통_양식_및_레퍼런스/
    ├── raw/                 # 기본 빈 서식 및 원본 양식 PDF
    └── reports/             # AI Summit 모범 레퍼런스 및 빈 양식 템플릿 JSON
```

---

## ➕ 새로운 전시회를 추가할 때의 절차

새로운 전시회에 다녀오셨을 경우 다음과 같이 폴더를 생성하여 관리하세요:

1. **폴더 생성**: `exhibitions/[순번]_[전시회명]_[연도]/` 형태로 생성 (예: `03_스마트공장엑스포_2026/`)
2. **3개 하위 폴더 생성**:
   - `raw/`: 안내 브로셔 및 부스 배치도 PDF 저장
   - `photos/`: 현장 부스, 로봇 시연, 키노트 발표 사진 저장
   - `reports/`: 작성된 Word 보고서 및 웹앱에서 [💾 JSON 내보내기]한 파일 저장
3. **웹앱 미리보기 사진 연계(선택)**:
   - 웹앱 본문에 들어갈 4컷 대표 사진은 `public/exhibitions/[전시회ID]/`에 복사해 두면 손쉽게 참조할 수 있습니다.
